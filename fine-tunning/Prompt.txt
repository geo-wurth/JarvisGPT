Você é um desenvolvedor especializado em web scraping e transformação de dados. Seu objetivo é extrair perguntas e respostas de um arquivo HTML de FAQ e convertê-las para o formato JSONL, estruturado especificamente para treinamento de chatbots.

**Estrutura do HTML que você receberá:**
- Um div com classe `"página-texto"` contendo 3 seções de FAQ
- Três divs principais com ids: `"Perguntas"`, `"PerguntasTrabalhar"` e `"PerguntasEmpresas"`
- Dentro de cada seção, múltiplos elementos com classe `"panel panel-default panel-pergunta"`
- Cada painel contém:
  - Uma div com id `"p1"`, `"p2"`, `"p3"` etc. (contém a pergunta em uma tag `<button>`)
  - Uma div com id `"pergunta1"`, `"pergunta2"`, `"pergunta3"` etc. (contém a resposta em um ou mais elementos `<p>`)

**Seu trabalho:**
Extraia as perguntas e respostas do HTML fornecido e converta cada par para o seguinte formato JSONL:

```
{"messages": [{"role": "system", "content": "Jarvis é um chatbot pontual e muito simpático que ajuda as pessoas"}, {"role": "user", "content": "<PERGUNTA DO FAQ>"}, {"role": "assistant", "content": "<RESPOSTA DO FAQ>"}]}
```

**Instruções importantes:**
- Processe **5 perguntas por vez** para não ultrapassar o limite de tokens
- Extraia o texto da pergunta da tag `<button>` dentro de cada div `p[número]`
- Extraia o texto da resposta concatenando o conteúdo de todos os elementos `<p>` dentro da div `pergunta[número]` correspondente
- Mantenha a formatação e a pontuação originais das respostas
- Cada linha do output deve ser um objeto JSON completo (formato JSONL)
- Processe as seções na ordem: `Perguntas`, depois `PerguntasTrabalhar`, depois `PerguntasEmpresas`

Ao participarem do programa, micros, pequenos e médios estabelecimentos industriais passam por seis etapas de consultoria gratuita, focada na redução de emissões de Gases de Efeito Estufa (GEE), além de capacitações e acesso à ferramenta para realizar o Inventário de Emissões de GEE de forma autônoma. As indústrias interessadas podem inscrever-se através do site <a href="https://jornadadescarbonizacao.sp.senai.br/" target="_blank" rel="noopener">jornadadescarbonizacao.sp.senai.br</a>.</p>
